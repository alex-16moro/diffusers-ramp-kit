# Diffusers Contribution Ramp Kit

The kit lives in [`diffusers-ramp-kit/`](diffusers-ramp-kit/).

Start with [setup and the engineer demo](diffusers-ramp-kit/START_HERE.md), then read the [current evidence and remaining acceptance gates](diffusers-ramp-kit/FINAL-REVIEW.md).

Repository CI runs unit checks, validates the release manifest, and performs a documented-bootstrap CLI rehearsal with a local base-policy CI simulation. A clean Cursor session and a real Diffusers fork PR are separate acceptance gates.
